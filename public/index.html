Endpoints da API

MétodoRotaDescrição
GET/healthStatus e versão
GET/api/tasksLista tarefas
GET/api/tasks/:idBusca por id
POST/api/tasksCria tarefa
PATCH/api/tasks/:id/completeConclui tarefa
DELETE/api/tasks/:idRemove tarefa

Modelo de branches

main → produção, protegida por tags de versão.
develop → integração.
feature/*, release/*, hotfix/* → fluxo Gitflow.
